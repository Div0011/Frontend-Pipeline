# Accessibility Audit Skill (/a11y-audit)

Source reference: [ux-ui-agent-skills/accessibility](file:///Users/divyansh/Documents/GitHub/Frontend%20Pipeline/skills/ux-ui-agent-skills/accessibility)

## Usage
Use `/a11y-audit` to verify POUR principles (Perceivable, Operable, Understandable, Robust), check focus rings, tap target sizes (≥44px), contrast ratios (≥4.5:1), and ARIA patterns.
