## Usage
Use `/design-component` when specifying atomic UI components, layout organisms, or data display widgets.

### 8 Mandatory States
1. Default
2. Hover
3. Active / Pressed
4. Focus / Focus-visible
5. Disabled
6. Loading / Skeleton
7. Error / Invalid
8. Success / Valid
