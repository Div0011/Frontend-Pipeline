# Design Tokens Skill (/design-tokens)

Source reference: [ux-ui-agent-skills/tokens](file:///Users/divyansh/Documents/GitHub/Frontend%20Pipeline/skills/ux-ui-agent-skills/tokens)

## Usage
Use `/design-tokens` when defining or extending design token schemas, generating accessible color palettes, or configuring multi-brand light/dark theme variables.

### Key Rules
- All colors must include explicit role mappings (bg, text, border, surface, accent).
- Color contrast ratios must meet WCAG 2.2 AA standards (4.5:1 for normal text, 3:1 for large text).
- Spacing scales must follow a strict 4pt/8pt grid rhythm.
