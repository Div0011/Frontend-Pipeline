# Pattern Analysis: Jeton — Fintech SaaS Product Launch

## Genre: SaaS Product Launch — Premium Motion Without Gimmicks (Genre 2)

## Core Architecture
- **Stack:** Next.js + GSAP + Framer Motion
- **Approach:** Serious product flow with premium motion
- Every animation serves the product narrative, nothing is decorative

## Key Mechanical Patterns

### 1. Serious Product Flow
- Clean, linear scroll narrative with clear feature sections
- Each section has a single message + single visual
- No competing animations within a viewport
- Motion is used to *clarify* the product, not impress

### 2. Scroll → Feature Highlight
- As user scrolls through a feature, relevant UI elements highlight
- Highlight is subtle: color shift, border glow, counter increment
- Scroll never fights the user — slow scrub reveals information
- Feature comparison uses horizontal scroll with sticky headers

### 3. Restrained Color Palette
- Primary: Deep blue/navy (#0A1628)
- Secondary: Clean white (#FFFFFF)
- Accent: Single brand color (teal/green for fintech trust)
- No gradients, no overlays — flat colors for maximum readability

### 4. Typography Hierarchy
- Display: Bold geometric sans (for headlines)
- Body: Clean sans-serif with generous line-height
- Data/numbers: Tabular figures for financial precision
- Character spacing increased for premium feel

## Why It Works
- Fintech requires trust — motion must feel precise, not playful
- Restraint in color and animation signals maturity
- Each feature gets its own moment — no information overload

## Extraction For Template 2
- Clean, linear scroll narrative with single-message sections
- Scroll → feature highlight system (color shift, glow)
- Horizontal scroll for feature comparison
- Restrained fintech-friendly color palette
- Tabular figure typography for data
