# Pattern Analysis: L'Oréal Groupe Mediaroom — Corporate / Institutional

## Genre: Corporate / Institutional — Mega-Menu Sophistication (Genre 3)

## Core Architecture
- **Stack:** Enterprise CMS + Custom frontend
- **Approach:** Institutional gravitas through restrained design and mega-menu sophistication
- Content density managed through progressive disclosure

## Key Mechanical Patterns

### 1. Mega-Menu Architecture
- Full-width mega-menu on hover/click of navigation items
- Menu organized in 3-column grid:
  - Column 1: Primary categories (brands, news, innovation)
  - Column 2: Sub-categories with descriptions
  - Column 3: Featured content (latest press release, hero story)
- Persistent search bar in header
- Menu animations: opacity + slight Y translation (0.3s ease)

### 2. Restrained Palette
- Primary: Clean white background (#FFFFFF)
- Text: Dark charcoal (#1A1A1A)
- Accent: Single brand color (L'Oréal red)
- Grays for hierarchy (section headers, metadata)
- No gradients, no heavy shadows — flat, clean

### 3. Content Hierarchy
- News/articles displayed in card grid
- Each card: image (16:9) + category tag + headline + date
- Category tags color-coded (press releases = red, innovation = blue)
- Cards have subtle hover lift (translateY -2px, shadow increase)
- Featured content gets 2x width card

### 4. Typography for Institutional Trust
- Display: Serif font for hero headlines (tradition, authority)
- Body: Clean sans-serif (readability)
- Data: Monospace for numbers/stats
- Large line-height (1.6+) for readability
- All caps category labels in small caps

## Why It Works
- Instant brand recognition through consistent palette
- Mega-menu reveals depth without overwhelming
- Card grid makes large content libraries scannable
- Typography conveys institutional authority

## Extraction For Template 3
- Mega-menu architecture with 3-column grid
- Restrained corporate color palette
- Card grid with category tagging system
- Progressive disclosure for content density
- Serif + sans-serif typography pairing
- Hover card lift and shadow transitions
