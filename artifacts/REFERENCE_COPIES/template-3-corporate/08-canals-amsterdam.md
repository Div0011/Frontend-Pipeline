# Pattern Analysis: Canals Amsterdam — Corporate / Institutional

## Genre: Corporate / Institutional — Atmospheric Cinematic Pacing (Genre 3)

## Core Architecture
- **Stack:** Next.js + GSAP + Custom video player
- **Approach:** Cinematic pacing with atmospheric grading
- Chapter backgrounds modeled as layered scenes

## Key Mechanical Patterns

### 1. Chapter-Based Atmospheric Grading
- Each chapter has a distinct color grade/atmosphere:
  - Chapter 1: Warm golden hour (Amsterdam canals at sunset)
  - Chapter 2: Cool blue (night/water reflections)
  - Chapter 3: Soft neutral (interior/cultural spaces)
- Grade shifts are smooth 2-3s transitions between sections
- Background video loops with subtle parallax

### 2. Pacing Rhythm
- Long-form storytelling with deliberate pacing
- Each chapter: 30-45 seconds of scroll time
- Text appears slowly, line by line
- Between chapters: moment of stillness (only ambient sound/no motion)
- Rhythm: text → visual → reflect → next chapter

### 3. Background Media Layers
- Primary: Fullscreen video with 0.5x playback speed
- Secondary: Overlay gradient (top-to-bottom, 50% opacity)
- Tertiary: Particle overlay (subtle, not distracting)
- All layers scroll with parallax at different speeds

### 4. Typography for Narrative
- Serif font for chapter titles (tradition, cultural weight)
- Sans-serif for body text (readability)
- Large pull quotes centered, italic
- Chapter numbering: Large numeral (120px+) as background element

## Why It Works
- Color grading sets emotional tone for each chapter
- Slow pacing gives space for reflection
- Parallax layers create depth without 3D
- Deliberate stillness between chapters prevents fatigue

## Extraction For Template 3
- Chapter-based color grading with smooth transitions
- Parallax background layers at different speeds
- Pacing rhythm: text → visual → reflect → next
- Serif chapter titles + sans-serif body
- Large chapter numerals as design elements
- Slow-motion background video loops
