## 2. Integrated Slash Commands

- `/design-tokens`: Generate / extend / validate DTCG tokens, color roles, 4pt spacing scale, light/dark mode variables.
- `/design-component`: Spec components across 8 interactive states (Default, Hover, Active, Focus, Disabled, Loading, Error, Success).
- `/design-code`: Framework adapters for Next.js 14, React 18, Tailwind CSS v3/v4 with 1:1 token fidelity.
- `/design-review`: Score designs across 6 dimensions + Nielsen 10 Usability Heuristics.
- `/a11y-audit`: WCAG 2.2 AA/AAA contrast checks (≥4.5:1 text, ≥3:1 UI), visible focus rings, tap target checks (≥44px).
- `/apply-aesthetic`: Apply high-taste design archetypes or select from 138 curated themes.
- `/redesign`: Audit-first upgrade of existing UI/UX without breaking core functionality.
- `/migrate-design-system`: Token mapping to/from Material 3, Apple HIG, shadcn, Radix, etc.
- `/prototype`: Wireframe progression, micro-interaction specs, usability testing plans.
- `/ux-writing`: Craft concise microcopy, action-oriented CTAs, empty states, and empathetic form errors.
- `/figma`: Extract Figma tokens, auto-layout frames, and design specs.
- `/theme-factory`: Harmonize HSL color palettes and CSS theme variable generation.
- `/brand-guidelines`: Enforce visual voice, brand rules, logo placement, and design consistency.
- `/canvas-design`: 2D HTML5 canvas shaders, particle backgrounds, and interactive visual surfaces.
- `/skill-creator`: Package and publish new agent skills.
- `/design-sprint`: 5-phase design sprint process (Understand, Ideate, Decide, Prototype, Test).
- `/hooked-ux`: Habit-forming engagement loops and retention-oriented user flows.
- `/ux-heuristics`: Nielsen & Molich heuristic audit and friction diagnosis.
- `/apple-design`: Apple HIG standards, glassmorphism, SF typography, and fluid spring physics.

## 3. Quality & Taste Verification Protocols

1. **Zero Emoji Rule**: Zero emoji in production UI, code, JSON, copy, comments, or status logs. Use inline SVG Lucide icons.
2. **Empirical Contrast Measurement**: Never claim WCAG compliance without computed contrast values for light and dark themes across all component states.
3. **8-State Completeness**: Every button, input, card, modal, tab, and form control must specify default, hover, active, focus, disabled, loading, error, and success states.
4. **Responsive Reflow**: Zero horizontal scrollbar or element overflow down to 280px viewports.
