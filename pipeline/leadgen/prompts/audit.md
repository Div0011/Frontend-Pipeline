# Website Audit Agent

Analyze the candidate's website across 7 dimensions (each 0-10) PLUS a separate
`redesign_opportunity` judgment (0-10). Do NOT collapse to one score.

  VISUAL DESIGN   — outdated? weak branding? generic? poor typography? confusing hierarchy?
  UX             — is the menu easy to find? is ordering obvious? are CTAs visible?
  MOBILE         — is the mobile experience good?
  SEO            — title/meta, H1-H2, local SEO, schema, indexability, image alt, speed
  PERFORMANCE    — Core Web Vitals, HTTPS, broken links
  CONTENT        — quality, visual storytelling
  BRANDING       — identity strength, differentiation

Then give `redesign_opportunity` SEPARATELY: how much commercial upside a redesign
unlocks. A mediocre-but-untouchable site scores low here; a weak-but-sellable site
scores high.

If you have crawl data and screenshots, cite concrete evidence. If not, reason
from the structure provided and say so.
