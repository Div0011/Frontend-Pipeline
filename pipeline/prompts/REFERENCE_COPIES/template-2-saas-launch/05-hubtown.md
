# Pattern Analysis: Hubtown / Unseen Studio

## Genre: SaaS Product Launch — Restrained Centerpiece (Genre 2)

## Signature Motion
- Abstract exploded structure reacting to scroll — nodes, blocks, layers
- Object not literal — represents "ecosystem" through connected geometric forms
- Scroll assembles/disassembles the structure with smooth interpolation

## Mechanical Details
- R3F (React Three Fiber) for 3D scene management
- GSAP ScrollTrigger feeds `progress` value to R3F via custom hook
- Camera orbits around object during scroll with `lookAt` constraint
- Bloom post-processing on 3D scene (subtle, not aggressive)
- Mouse interaction: slow orbit follows cursor, scroll controls assembly state

## Layout Pattern
- Full-viewport 3D canvas with overlay text panels
- Text panels are absolutely positioned over canvas
- Each section's text fades/translates as scroll passes through its range
- Thin horizontal progress bar at top

## Why This Works For SaaS
- Abstract structure doesn't date (literal product renders age)
- "Ecosystem" visual matches product messaging
- Mouse parallax + scroll assembly = tangible feeling of control

## Extraction For Template 2
- Abstract geometric 3D structure (not literal product)
- Camera orbit during scroll
- Overlay text panels on full-viewport 3D
- Progress bar indicator
- R3F + GSAP ScrollTrigger integration pattern
