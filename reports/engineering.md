# Frontend Engineering

**Stack:** Next.js + React + TypeScript + Tailwind CSS + GSAP + Framer Motion + Lenis + Three.js + @react-three/fiber + @react-three/drei

This code is a basic implementation of the Smash Guys website. It includes the necessary components, layouts, and configurations for a cinematic food brand. The code uses Next.js, React, TypeScript, Tailwind CSS, GSAP, Framer Motion, Lenis, Three.js, and other libraries to create a high-end burger kitchen experience.
