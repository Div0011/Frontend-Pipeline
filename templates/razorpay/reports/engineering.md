# Frontend Engineering

**Stack:** Next.js (App Router) + React + TypeScript + Tailwind CSS + GSAP + Framer Motion + Lenis + Three.js + @react-three/fiber + @react-three/drei

This is a basic implementation of the Razorpay website using the specified technologies. Please note that this is a simplified version and may require additional development to meet all the requirements.
