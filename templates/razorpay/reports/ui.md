# UI Design System

A design system that embodies the spirit of innovative financial solutions, embracing a bold and cinematic approach

## Spacing
- token: 4pt
- value: 4px

## Color Palette
- Near-Black: #1a1d23 (base)
- Electric Blue: #03a9f4 (accent)

## Components
### Button
A button component with a magnetic/hover life
Variants: default, hover, active, disabled, focus

### Card
A card component with a custom emoji/icon system
Variants: default, hover, active

### Nav
A navigation component with a custom design
Variants: default, hover, active

### Hero
A hero component with a custom design
Variants: default, hover, active

### Footer
A footer component with a custom design
Variants: default, hover, active


## Responsive Layouts
An asymmetric grid that reflows at 3 breakpoints without collapsing into centered stacks
